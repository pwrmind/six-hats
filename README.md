# GigaCode Six Hats Skills

Набор из 6 навыков (`SKILL.md`) для ИИ-ассистентов GigaCode, VS Code, JetBrains IDE и других Agent Skills-совместимых сред.

Реализует метод шести шляп мышления Эдварда де Боно для анализа идей, фич, архитектуры, рисков и UX.

## Состав

| Навык | Роль | Назначение |
|---|---|---|
| `blue-hat` | Оркестратор | Управляет дискуссией, сводит итог |
| `white-hat` | Факты | Данные, метрики, ограничения, стандарты |
| `yellow-hat` | Выгоды | Ценность, плюсы, лучший сценарий |
| `black-hat` | Критика | Риски, уязвимости, edge cases, техдолг |
| `green-hat` | Креатив | Альтернативы, нестандартные решения |
| `red-hat` | Эмоции | UX, страхи, восторги, человеческий фактор |
